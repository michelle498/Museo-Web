# Museo Web de la Evolución Gráfica

Proyecto elaborado para reunir en una sola página las actividades sobre evolución gráfica, aplicación real, laboratorio de color, algoritmo RGB → HSV, glosario y conclusión.

## Archivos principales

- `index.html`: estructura semántica del museo.
- `styles.css`: estilos responsivos.
- `assets/`: ilustraciones SVG usadas en la página.

## Cómo abrirlo localmente

1. Descarga o copia la carpeta completa.
2. Abre `index.html` en tu navegador.
3. Revisa que se vean las imágenes de `assets/`.

## Cómo subirlo a GitHub

1. Crea un repositorio público nuevo.
2. Sube `index.html`, `styles.css`, `README.md` y la carpeta `assets`.
3. Verifica en GitHub que todos los archivos hayan quedado visibles.

## Cómo publicarlo en Vercel

1. Inicia sesión en Vercel.
2. Elige **Add New → Project**.
3. Importa el repositorio de GitHub.
4. Conserva la configuración por defecto del sitio estático.
5. Pulsa **Deploy**.
